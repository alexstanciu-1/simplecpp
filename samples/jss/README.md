# JSS Samples
Doc Status: planning

This directory holds manually converted JSS samples that mirror selected files from `tests/php/*/level_*/*.phs`.

These samples are not generated by a conversion script. Codex converts them manually in small batches so each JSS sample can be reviewed against the source PHS intent and the current JSS frontend surface.

Each sample should usually have:

- `<name>.jss`
- `<name>.expected.phs`

The expected PHS file records the current JSS-to-PHS frontend output. Full build/run parity can be added later as the JSS frontend and STAN integration mature.
