# Accounting checkpoint archive
Doc Status: supporting

These reports, scripts, patches and summaries were archived from
commit `2f453540a278c60d5c1c4bf6e2a03682d692607b` of the isolated accounting checkout.
[Provenance](provenance.json) records original paths and separate source/archive SHA-256 hashes.
Links to dependencies outside this bounded archive are preserved as explicit
historical path citations rather than dead links. Other content is unchanged.
The source tree and generated binaries are not copied. Reproduction scripts retain
original layout/path assumptions: run them in a checkout of that revision using
their original paths, rather than directly from this archive. Raw historical paths
are provenance, not promises that temporary files still exist. No benchmarks were
rerun during archiving.
