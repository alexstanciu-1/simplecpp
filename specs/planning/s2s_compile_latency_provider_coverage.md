publication, then test the unchanged fifteen-commit sample under that candidate.
The earlier compound analogue took 8.275 s native (9.775 s with the assumed
frontend), but its historical feature check and coverage attribution remained open.

the exact historical fixture. Retain both executables for existing runner row
exports. Setup/conversion costs are not incremental edit timings.

After restoring the candidate, freeze output policy and run all eleven textually
eligible cases in the unchanged fifteen-commit sample. Keep four context limits,
semantic incompatibilities and comment-only edits distinct. Use three equivalent
native dirty work sets per fast case; preserve one successful screen above twenty
seconds. Full smoke and literal-to-LLVM/native-exit42 checks remain required for
accepted timings. No output-policy tuning during the corpus.

Production integration, compiler feature fixes, and full historical twelve-source
revision reconstruction remain outside this assessment.

## Paired fixture outcome

policy and restored provider candidate both return process exit0, completed=0,
blocked=1 and no LLVM artifact. The initial candidate check agrees. This establishes
that lack of completion predates provider publication in this workload; it does
not turn the fixture into a passing feature test. Retained executables allow a
follow-up comparison of detailed blocked-layer/reason rows.

The previous-policy row export identifies `backend_text`, blocked reason5
(`backend_text_not_ready`). The current source describes this runner as a tiny
transition runner following retirement of the old broad proof harness. Do not
infer a more specific compiler defect from the aggregate status alone.

## Conclusion and remaining material

The provider-publication candidate retains all nine fixed-corpus code passes
while addressing the separate compound-layout exception. This strengthens the
case for informed, stable per-callable and per-type output. It does not establish
a population-wide success rate, optimized/release-build latency, or full historical
feature support. The compound estimate remains near ten seconds with little
headroom.

Next broaden the independent history sample beyond these fifteen commits and
study the excluded/coordinated changes in coherent source surroundings. The full
twelve-source/53-method `7d58f273` change is still unmeasured; the twenty-field
analogue covers only its layout component. Keep genuinely broad complete-type
changes distinct from avoidable shared-header invalidation. Retain negative
feature controls and exact replay limits in subsequent assessments.
