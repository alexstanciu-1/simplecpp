# PHP flavor mixed API inventory and developer priorities

Doc Status: planning

Reviewed at `4e035377d`. The [developer walkthrough](php_flavor_developer_qos.md) records 33 tasks and eleven applications at an earlier revision. This report reconciles that evidence with the current source contracts. The original application matrix was not rerun for this discussion.

## Agreed direction

Use native types when the input or result has a clear type. Convert the two CLI argument-list aliases, then finish the PHP regex family as a family. Defer cases that require selector-by-selector curl mapping or a new heterogeneous representation.

The original PHP experience evidence is the [developer walkthrough](php_flavor_developer_qos.md), first committed as `7c53f16d5`, with [its runnable applications and probes](../../samples/php-developer-qos/README.md). Its 33 developer tasks and four original priorities are the starting point for that discussion. The suggestions below are a later synthesis.

## Where a PHP caller encounters mixed

The inventory uses the current runtime catalog and an all-options compiler publication generated in a temporary directory using the repository’s CMake publication recipe. It includes source aliases, overloads, result payloads, callback rows and compiler-specialized operations. PHP projects need the corresponding optional module, and general names also need project opt-in. Merely being able to pass a checked mixed string to a typed string parameter does not make that helper a mixed API.

| Family and source names | Observable use of mixed | Proposed disposition |
| --- | --- | --- |
| JSON — PHP/general `json_encode`, general `json_decode_mixed` | Encode accepts a mixed tree among its overloads and returns `result<string>`. The explicit decoder returns `result<mixed>`. PHP `json_decode` returns `result<dynamic>`. PHP/general `json_decode_as` accepts text and a record type marker. Eligible data records also encode directly. | Keep the open-data path. Show the typed record, mixed value tree, shared dynamic tree and document-node choices together. |
| Core — PHP/general `is_bool`, `is_int`, `is_float` | The operand must already be mixed. They observe its stored kind, return bool and do not narrow the original variable. | Keep exact observations. Review `is_string` and a container test together, then decide which observations to publish for dynamic. |
| Core — PHP `number_format` | Native int and float callers have direct overloads. Mixed and dynamic callers need a runtime numeric-kind choice for the first argument. | Keep dispatch for the unknown case. Use this as the example of a declared scalar choice. |
| CLI — PHP `cli_args`, `cli_argv` | Both return mixed snapshots of the argument strings. General `cli_arguments` already returns `vector<string>`. | Change both PHP aliases to return native vector<string>. Reuse the general argument-list implementation and migrate callers that declare a mixed snapshot. |
| Regex output — PHP `preg_match`, `preg_match_all` | An explicitly supplied matches argument can be an exact writable mixed slot. Typed numbered and named outputs cover the native capture shapes. The function result is a falseable integer. | Keep both. Show a typed matches slot first, including how the flags affect its cell type. |
| Regex collections — PHP `preg_grep`, `preg_filter` | The mixed overload consumes a mixed subject and returns `result_or_false<mixed>`. Bare list subjects select mixed. Declared vector and hash subjects have native overloads. Scalar `preg_filter` returns `?string`. | Finish the preg_* family review. Prefer native types for a known input or output shape and record genuinely heterogeneous cases for later. Include literal inference and existing callers in that review. |
| Regex callbacks — PHP `preg_replace_callback`, `preg_replace_callback_array` | A callback can receive a mixed capture row. An unannotated inline callback defaults to it. One typed vector or hash row can cover the whole call. The result follows the subject. | Include callback defaults in the family review. Demonstrate typed rows for known shapes and defer ambiguous capture interfaces. |
| curl — PHP `curl_setopt`, `curl_getinfo`; general `curl_request_getinfo` | PHP setopt has direct string, integer, bool and string-vector inputs alongside mixed. PHP getinfo returns a boxed scalar for a selector, a table without one, or boxed false on error. The general selector returns `result<mixed>`. | Defer selector-dependent typing. General `curl_request_exec` already returns a checked response record with typed fields. |
| mysqli — PHP statement method `bind_param` | The variadic slot proof admits a named mixed slot alongside integer, float and string slots. Values are read on execute. A fetched row is dynamic, and general `db_execute` takes dynamic values. | Keep the distinction between a borrowed slot and a one-shot value list. Revisit checked statement extraction under the existing lifetime proof. |
| General collections — `collection_map`, `collection_filter` | A table-valued mixed input passes mixed elements to the callback and returns a mixed table preserving the original keys. Map takes same-family callback results; filter takes bool. Typed hashes and vectors use their native paths. | Keep. Review PHP collection aliases against actual PHP key, arity and callback behavior. |
| Box operations in PHP source | `count`, `empty`, keyed `isset`, and mixed receiver methods `has`, `remove`, `clear` operate on boxed values. Indexing, iteration, append, `clean` and explicit casts are language operations. `clear` empties the container; `clean` resets the binding. | Document these once with examples for missing, stored null, zero and an empty collection. |

The generated registry contains **15 distinct PHP free-function names** with an explicit mixed signature or mixed callback row, counting the two CLI aliases separately. The method, compiler-specialized collection helpers and language operations in the last three rows extend that inventory. The optional filesystem, stream I/O, process, datetime, FastCGI, UI and Webview publications supply no additional explicit mixed signatures. Current PHP `preg_split`, `preg_split_offsets` and `preg_replace` have native results. Exact writable outputs and typed parameters that accept checked projection belong to the admission review. ## PHP developer adjustments to discuss

| Area | Adjustment and a concrete acceptance example |
| --- | --- |
| Inspecting request values | Decide the exact string and container predicates for mixed and dynamic. A handler receiving JSON should be able to distinguish a missing field, a present null, false, and a value of the wrong kind. Use a typed record for known schemas and a document for object/list fidelity or strict byte validation. |
| Call and build diagnostics | For an unsupported builtin call, show the received argument type and the relevant accepted signature. Distinguish a missing runtime module from a disabled general spelling where the catalog can identify it. Use `json_decode($text, true)` and an unavailable JSON provider as acceptance examples. Keep exact writable-slot diagnostics. |
| First PHP file and project layout | Give actionable feedback for opening tags, `declare(strict_types=1)`, `require_once`, explicit entry returns and accidentally discovered stock PHP test files. Document CLI aliases and module selection in a small first project. Review `$argc` and `$argv` in the dedicated flavor pass. |
| Collections, storage and ownership | Audit familiar array lookup/map/filter idioms, nested boxed reads and writes, field/storage positions and defaulting. Show whether a write changes a copy or a shared alias, and whether a filter keeps the original keys. Keep reference binding restricted to proven storage. |
| Web request and output helpers | Start with flat form/query decoding and encoding. Specify duplicate keys, malformed escapes, plus versus space and byte handling. Treat HTML text/quoted-attribute escaping and CSV parsing/writing as separate contracts. Show the FastCGI equivalents of request body, status and response headers. |
| Output and familiar syntax | Improve echo diagnostics for bool, byte and boxed values; decide their formatting explicitly. Triage interpolation, nullsafe access, enum lookup, spread/destructuring and constructor promotion by observed application friction. Treat division, numeric-looking string comparison and byte indexing as documented semantic choices. |
| Optional libraries | Defer curl selector-specific mapping. Recheck mysqli prepare/check/bind using the ticket-report application. Review filesystem append flags/path edge cases and PHP datetime aliases separately. |

### Findings already addressed or narrowed

The incremental save/rebuild issue, carrier equality and checked conversions, decimal string-to-int conversion, string emptiness, single-entry typed-hash `isset`, reference diagnostics and shared PHP by-value argument admission all have subsequent work. Current record JSON encoding, typed record decoding, explicit exports of supported vectors/data records, and typed regex overloads also supersede parts of the original observations.
