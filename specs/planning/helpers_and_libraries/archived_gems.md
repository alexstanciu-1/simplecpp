# Additional v0.1 mining leads

Doc Status: planning

Scanned the release tree at `d2f63e37e` and the later frozen archive at `afb1f6844` through Git. The search covered native modules and hosts, the PHP integration, the portability function map and its source facades, the accounting reference applications, runtime probes, developer tools and their fixtures. FastCGI was the sole entry under the release runtime hosts directory. The recommendations below reflect code or fixtures present in the donor. They do not extend the approved Stage 1 contract.

| Candidate | What is worth recovering | Boundary in v0.2 |

| Content SHA-256 | The portability map explicitly publishes `content_sha256(bytes)`; its PHP implementation calls the platform SHA-256 and the native target delegates to the publisher's byte digest. A private incremental state also feeds digests from files. | Published as a general helper taking a byte string and returning exactly 64 lowercase hex digits. No filesystem dependency is necessary for the byte operation. The existing `hash_string` contract remains FNV-1a 64-bit. The compiler's host-PHP SHA-256 calls do not publish a source helper. [Donor map](https://github.com/alexstanciu-1/simplecpp/blob/afb1f6844/v0.1/tools/php_portability/function_map.php) · [Native digest](https://github.com/alexstanciu-1/simplecpp/blob/afb1f6844/v0.1/runtime/include/modules/filesystem/detail/output_sha256.hpp) |

A temporary Clang probe built the unmodified donor digest header. One-shot and byte-at-a-time updates both matched Python hashlib for nine inputs: empty, abc, embedded NUL, all 256 byte values, and lengths 55, 56, 63, 64 and 65. This checks byte handling and padding boundaries. Provider choice, maintenance and performance remain implementation questions. No other candidate was executed in this scan.
