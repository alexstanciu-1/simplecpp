# Planning Notes
Doc Status: supporting

Purpose: provide the default home for temporary planning notes and task-scoped design working documents under `specs/`.

Use this folder for:

- temporary task plans
- design sketches
- migration notes
- working discussion documents that are not yet normative

Rules:

- planning notes placed here should include `Doc Status: planning`
- notes here do not override normative specs
- if a note becomes authoritative, promote it intentionally to the correct owning spec location
- temporary task notes may be removed when the task is complete
